Accéder à la saisie

L'application ne demande ni compte ni mot de passe : l'accès se fait en scannant le QR code affiché dans le service.

Comment faire

  1. Ouvrez l'appareil photo de votre téléphone.
  2. Visez le QR code affiché dans le service et touchez le lien qui apparaît.
  3. Choisissez votre nom dans la liste (une seule fois).

Votre téléphone garde ensuite l'accès : vous n'aurez pas à rescanner à chaque fois.

Le message « QR code expiré » s'affiche ?

L'administratrice a remplacé le QR code (par exemple parce que l'ancien avait circulé hors du service). Scannez simplement le QR code actuellement affiché.

lightbulb Pour revenir plus tard, ajoutez simplement la page aux favoris de votre navigateur : pas besoin de rescanner.
